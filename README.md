## Avaliação

A disciplina é avaliada em três conceitos (C1, C2 e C3), cada um valendo 10,0 pontos e composto por:

- **A1** — avaliação escrita individual, estilo ENADE (5,0 pontos);
- **A2** — trabalho prático em grupo, entregue via repositório GitHub, sem apresentação (5,0 pontos).

A Média Parcial é `MP = (C1 + C2 + C3) / 3`. É aprovado quem obtiver frequência ≥ 75% **e** `MP ≥ 7,0` (com dispensa da Avaliação Final), ou Média Final `MF = (MP × 0,6) + (AF × 0,4) ≥ 5,0`.
